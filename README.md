# 🏦 CreditWise Loan System

##  Project Overview

CreditWise Loan System is a Machine Learning-based application that predicts whether a loan application is likely to be Approved or Rejected using applicant financial and personal information.

The project aims to improve the loan evaluation process through data analysis, feature engineering, and supervised machine learning.

##  Key Features
- Exploratory Data Analysis (EDA) and data preprocessing.
- Feature engineering and feature scaling.
- Implemented KNN, Logistic Regression, and Gaussian Naive Bayes.
- Model evaluation using Accuracy, Precision, Recall, and F1-Score.
- Interactive loan prediction using Streamlit.

## 🛠️ Technologies Used
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Jupyter Notebook | Streamlit
